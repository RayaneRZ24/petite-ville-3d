# Effet sonore de capture

`monster-kill.m4a` : échantillon audio de la vidéo Monster Kill fournie par l'utilisateur :
https://www.youtube.com/watch?v=v4I6mMilmio

Récupéré le 13 octobre 2026, piste audio AAC de la vidéo, sans modification sonore.
Le navigateur lit le fichier local, sans lecteur YouTube ni téléchargement à chaque capture.
Le bouton « Activer Monster Kill » autorise la lecture et joue une préécoute.
Les captures rapprochées partagent la phrase déjà en cours ; aucun empilement de sons.
Le volume de l'effet est indépendant de la musique Web Audio.
